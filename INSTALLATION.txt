================================================================================
  📋 WHAT YOU NEED TO DO NOW
================================================================================

STEP 1: Install Node.js (if not already installed)
   → Download from: https://nodejs.org/
   → Minimum version: 18.0.0
   → Check your version: node -v

STEP 2: Install Dependencies
   Open terminal in this folder and run:
   
   Windows (PowerShell/CMD):
      npm install
   
   Linux/Mac (Terminal):
      npm install

STEP 3: Configure Your Bot
   Edit the .env file in this folder with:
   
   REQUIRED:
   ✓ PRIVATE_KEY=your_wallet_private_key (without 0x)
   ✓ WALLET_ADDRESS=0xYour_Wallet_Address  
   ✓ TARGET_WALLETS=0xWallet1,0xWallet2 (wallets to copy)
   ✓ MONITORED_DEXES=pancakeswap,fourmeme (or just one)
   
   OPTIONAL (Telegram is NOT required!):
   ✓ TELEGRAM_BOT_TOKEN=your_bot_token (leave empty for CLI-only)
   ✓ TELEGRAM_CHAT_ID=your_chat_id (leave empty for CLI-only)

STEP 4: Build the Project
   npm run build

STEP 5: Verify Setup (optional but recommended)
   npm run check

STEP 6: Start the Bot
   npm start

================================================================================
  🎯 MULTI-DEX SUPPORT
================================================================================

This bot supports TWO DEXes:
✓ PancakeSwap V2
✓ four.meme

Configure which DEXes to monitor in .env:
   MONITORED_DEXES=pancakeswap,fourmeme    # Monitor both (default)
   MONITORED_DEXES=pancakeswap             # Only PancakeSwap
   MONITORED_DEXES=fourmeme                # Only four.meme

The bot will:
→ Detect which DEX the target wallet uses
→ Copy the trade on the SAME DEX
→ Display DEX name in CLI output

  📱 TELEGRAM (OPTIONAL)
================================================================================

Telegram notifications are COMPLETELY OPTIONAL!

The bot works perfectly in CLI-only mode. Add Telegram later if you want:

To enable Telegram (optional):
1. Message @BotFather on Telegram
2. Send: /newbot
3. Follow the instructions
4. Copy your bot token
5. Message your bot
6. Get your chat ID from:
   https://api.telegram.org/bot<YOUR_TOKEN>/getUpdates
7. Add both to .env file

Leave TELEGRAM_BOT_TOKEN and TELEGRAM_CHAT_ID empty for CLI-only mode.

================================================================================
  🆘 TROUBLESHOOTING
================================================================================

Problem: "Cannot find module"
Solution: Run: npm install

Problem: "PRIVATE_KEY is required"  
Solution: Edit .env file and add your private key

Problem: "No valid target wallets"
Solution: Check TARGET_WALLETS in .env (must start with 0x)

Problem: Build errors
Solution: Make sure TypeScript is installed (comes with npm install)

Problem: Trades from only one DEX detected
Solution: Check MONITORED_DEXES includes both DEXes

For more help, check:
- SETUP_GUIDE.md
- logs/error.log (after running)
- README.md troubleshooting section
